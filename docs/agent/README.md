# Agent 交互记录

本目录用于保存项目开发过程中可验证的 Agent Prompt / Result 记录。

## 真实性原则

- 只保存当前能够确认原始文本来源的交互。
- 不根据 Git history、commit message、README 或最终代码反向重构旧对话。
- Gate 0–5 的精确原始对话未保存在仓库，因此不会补写“看起来合理”的伪记录。
- Gate 6 以及之后两轮 UI polishing 的 Prompt / Result 有真实原文来源，因此已保留。
